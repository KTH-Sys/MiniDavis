# MiniDavis town artwork

`minidavis-town.png` is the square pixel-art backdrop generated with the built-in image generation tool. The team's MiniDavis cover was supplied as a style reference. The backdrop contains no residents; React overlays the five selectable animated SVG residents using the backend's actual tile coordinates.

This is decorative terrain. The original 12×12 world rules still govern movement; painted trees, buildings, fences and water do not introduce collision rules. Map labels mark logical locations, which may differ slightly from the artwork. The grid can be hidden with **Show grid**.

Walking interpolates each completed backend movement over 580 ms. Play also enables gathering motions, chimney smoke and pond sparkles. Pause stops those looping scene effects; a movement already received finishes. Reduced-motion preferences disable animation. The small sideways spread when residents share a tile is cosmetic.

The side journal displays executed decision explanations and the exact memory context supplied before that decision. Retrieval currently uses keywords. Interactions shows recorded social events involving the selected resident through `agent_id`, optional `target_agent_id`, or optional `participants`. The baseline engine currently emits movement, gathering, eating and resting only, so it has no conversations or trades to show. No dialogue is generated by the frontend.

## Generation prompt

```text
Use case: stylized-concept. Asset type: square background map for a real interactive 2D cozy town simulation called MiniDavis. Reference image is STYLE AND MATERIAL INSPIRATION ONLY: warm storybook pixel-art village, hand-placed square pixels, emerald foliage, honey stone paths, terracotta and blue slate roofs. Create a NEW square 2D top-down / slight three-quarter orthographic game board, a flat playable landscape seen from above, with even scale across the entire image, no horizon or sky and no central title. This will be a 12 by 12 simulation tile world over which we place separately animated tiny people. Treat coordinate x as left-to-right 0..11 and y as top-to-bottom 0..11. Open meadow dominates so characters can be seen; small forest grove around tile (2,2) in upper left; a clearly cultivated fenced golden/green farm at (9,3) in upper right; a little red-and-cream market stall around (5,5) and a small elegant clock-tower town hall around (6,5) near the center; one blue-roof cottage at (2,9) in lower left and one terracotta cottage at (9,9) in lower right. Paths connect these places through grassy squares. Keep buildings compact and leave their front entries clear. Little flowers, shrubs, fence segments, stacked logs, barrels, lampposts; soft dark-green trees frame the outer edges. A small sparkling pond is allowed only at the extreme lower-right corner as decorative scenery. Strong clean readable pixel art, crisp edges, appealing sunlit colors, detailed but simple enough to read as a small live game, no simulated camera blur. At most six main landmarks, exactly the mentioned locations. No people, no animals, no lettering, no numbers, no labels, no logo, no UI, no large title, no visible coordinate grid; our app renders its own interactive grid and actual characters. Output a square map image.
```
