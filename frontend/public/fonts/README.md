# Terminal font

The interface uses **Press Start 2P**, a bitmap-inspired pixel font by CodeMan38, to match the project's hacker-terminal reference. The town's small map labels use the system monospace font for readability.

The font is served locally, so no Google Fonts request is needed at runtime.

- Font: https://github.com/google/fonts/blob/main/ofl/pressstart2p/PressStart2P-Regular.ttf
- License: SIL Open Font License 1.1, included in `OFL-PressStart2P.txt`.
